# Reference Image Sources

**Status: prototype / proof-of-concept only — not distributed, not shipped.**
Per the project owner (2026-08-02), all images below are sourced from
whatever public page had a correct, verifiable visual match for the disease,
without formal license clearance — acceptable because this build never
leaves local/demo use. **Before any public release or distribution, redo
this sourcing pass with real license clearance** (see "Vetted open-license
sources" below for where to start that pass).

Every entry records source + author where available, so a real clearance
pass later doesn't start from zero. Every photo was visually checked against
the disease's written symptom description before being added — several
near-miss candidates (wrong crop, wrong disease stage, wrong pathogen) were
rejected during sourcing.

**Coverage: 24 of 25 diseases have at least one real reference photo.**
The exception, Groundnut Rosette Assistor Virus (GRAV), is intentional —
GRAV alone is scientifically asymptomatic (confirmed in the ICRISAT source
bulletin below); forcing a "symptom photo" would misrepresent the disease.

## Sourcing technique notes (for repeating this pass later)

- **PDF mining worked extremely well**: many university extension and
  CGIAR (ICRISAT/CABI) fact sheets are PDF-only with no HTML image gallery.
  `pdfimages -j <file> <prefix>` extracts embedded JPEGs directly; when
  images come back as `.ppm` (non-JPEG source, e.g. JPEG2000/CMYK), convert
  with Pillow. For fully scanned/flattened pages, `pdftoppm -jpeg -r 150`
  renders whole pages so figures can be visually located, then cropped.
- **Plantix** (plantix.net/en/library/plant-diseases/...) has one clean,
  consistently-named photo per disease page (`content.peat-cloud.com/w400/
  <slug>.jpg`) — check the page's own "Crops" list before using an image,
  since one physical page sometimes covers several crops with a photo of
  only one of them (e.g. its "Alternaria Leaf Blight" page photo is wheat,
  not sweet potato — rejected for that reason).
- **Bugwood.org / wiki.bugwood.org** blocked direct requests (403) all
  session; Bugwood-credited photos were still reachable indirectly via
  Wikimedia Commons and Plantix, which both host copies with attribution.
- **Infonet Biovision** timed out on every direct request this session
  (unrelated to the working link from the prior day) — worth retrying later.

## Vetted sources for a future real license-clearance pass

- **Infonet Biovision** (infonet-biovision.org) — CC BY-NC-SA on
  Biovision/icipe-credited photos; check each credit line.
- **Bugwood / IPM Images** — per-photo licensing varies by photographer.
- **CABI Plantwise Knowledge Bank** — licensing is per-resource.
- **Wikimedia Commons** — explicit machine-readable license tag per file.
- **University extension services & CGIAR bulletins** (NC State, LSU
  AgCenter, Arkansas, ICRISAT, CIP) — often public domain or CC-BY; check
  per publication.
- **Open-access journals** (MDPI, PMC/NCBI) — figures are typically
  CC BY under the journal's article license; confirm per article.
